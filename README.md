# Block Template - Complete Bootstrap HTML Template Collection

## 📋 Description

Ce repository contient une collection complète de templates HTML basés sur Bootstrap, incluant des pages d'atterrissage, des templates d'applications, et des composants modulaires. Le repository inclut également le projet spécialisé **KAYBIC AFRICA** - une plateforme d'agrégation de paiement mobile.

## 🚀 Contenu du Repository

### Templates et Pages Principales
- **index.html** - Template principal d'accueil
- **index-2.html** - Version alternative du template principal
- Pages d'authentification (signin, signup, password reset)
- Templates de blog et portfolio
- Pages de contact et à propos
- Templates spécialisés (comptabilité, finance, conférence, etc.)

### Projet KAYBIC AFRICA
Le dossier `Kaybic/` contient un projet complet de plateforme de paiement mobile pour l'Afrique francophone avec :
- API d'agrégation de paiements mobile money
- Documentation développeur complète
- Interface utilisateur responsive
- Support multi-opérateurs (Orange Money, MTN, Moov Money, Wave)

### Assets et Ressources
- **assets/** - Fichiers CSS, JavaScript, images et fonts
- **blocks/** - Composants modulaires réutilisables
- **docs/** - Documentation technique complète

## 🚀 Utilisation

### Démarrage Rapide
1. Clonez le repository
```bash
git clone https://github.com/AmedBah/template.git
cd template
```

2. Ouvrez `index.html` dans votre navigateur pour voir le template principal

3. Explorez le projet KAYBIC AFRICA :
```bash
cd Kaybic/
# Ouvrir Kaybic/index.html dans le navigateur
```

### Pour le Développement
1. Installez Node.js et npm
2. Installez les dépendances :
```bash
npm install
```
3. Lancez le serveur de développement :
```bash
npm start
```

## 🎨 Customisation

### Styles CSS
- Modifiez `/assets/css/theme.min.css` pour les styles globaux
- Ajoutez vos styles dans `/assets/css/custom.css`
- Utilisez les variables CSS pour la cohérence

### JavaScript
- Scripts principaux dans `/assets/js/theme.min.js`
- Ajoutez vos scripts dans `/assets/js/custom.js`
- Modules disponibles pour fonctionnalités spécifiques
